## Лабораторная работа №2

**Тема:** Разработка многостраничного web-сайта на HTML и CSS.

**Цель:** изучение основ HTML и CSS.

**Что сделано:**
- Многостраничный сайт (3 страницы: 22obebad, crypto, resonance).
- Навигация между страницами.
- Таблица с треками и разным выравниванием колонок (left, center, right).
- Внешний CSS-файл с селекторами по тегу, классу, id и псевдоклассами.
- Использование цвета, картинок, ссылок, аудио.
- Без JS и фреймворков.

**Структура:**
- `lab2/index.html` — главная страница.
- `lab2/page1.html` — таблица треков.
- `lab2/page2.html` — полка с книгами, играми, фильмами, музыкой.
- `lab2/style.css` — общие стили.
