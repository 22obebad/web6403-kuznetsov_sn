##  Лабораторная работа №3. Основы JavaScript

**Тема:** Реализация набора функций на языке JavaScript в соответствии с предоставленным каркасом проекта.

**Цель:** изучение основ языка JavaScript.

**Что сделано:**

- Проверка числа на целочисленность с использованием побитовых операторов.

- Генерация массива чётных чисел от 2 до 20.

- Вычисление суммы чисел с использованием цикла и рекурсии.

- Вычисление факториала числа.

- Проверка числа на принадлежность к степеням двойки.

- Вычисление N-го числа Фибоначчи.

- Функция выполнения операций с сохранением промежуточного результата.

- Генератор арифметической последовательности.

- Рекурсивное сравнение объектов по содержимому.

- Используемые технологии: JavaScript, Node.js, Mocha.
